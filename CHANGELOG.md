# Changelog

## Текущая рабочая версия

- Подготовлен portable-установщик для Windows 10 без запроса прав администратора.
- Все основные компоненты разворачиваются в целевую папку, например `H:\LLM`.
- Добавлена установка embedded Python 3.12.3 внутрь portable-папки.
- Добавлена установка Open WebUI в `OpenWebUI\packages`.
- Добавлена распаковка CUDA 12 сборки `llama.cpp`.
- Добавлена обязательная проверка и распаковка `cudart` архива из того же релиза `llama.cpp`.
- Добавлены корневые `Start-PortableLLM.cmd` и `Stop-PortableLLM.cmd`.
- Добавлены PowerShell-скрипты запуска и остановки в `scripts`.
- Добавлен выбор модели, если в папке `models` лежит несколько `.gguf` файлов.
- Добавлен автоматический подбор свободных портов для `llama-server` и Open WebUI.
- Добавлена проверка CUDA backend перед запуском, чтобы не уходить молча в CPU.
- Добавлена предварительная оценка VRAM перед запуском модели.
- Добавлены базовые параметры `llama.cpp` в `config\portablellm.ini`.
- Добавлена поддержка CUDA/VRAM-ориентированных настроек: `GpuLayers`, `CtxSize`, `FitTargetMiB`, `CpuMoe`, `NCpuMoe`, `NoMmap`, `Metrics`.
- Добавлено отключение фоновых задач Open WebUI, которые могли создавать скрытую нагрузку на модель.
- Добавлена подробная русскоязычная документация в `readme.md`.
- Репозиторий очищен от старой нетестированной версии скриптов с суффиксом `-v1`.

## Примечания

- Модели, архивы `llama.cpp`, архивы `cudart`, логи и установленная portable-среда не входят в репозиторий.
- Производительность зависит от модели, квантования, GPU, драйвера, размера контекста и параметров `llama.cpp`.
- Текущие параметры запуска являются рабочими стартовыми настройками, а не универсальным оптимумом для любого железа.
