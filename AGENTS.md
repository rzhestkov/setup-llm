# Инструкции для агентов

## Кодировка и PowerShell

- Хранить текстовые файлы проекта в UTF-8.
- Все файлы `*.ps1`, содержащие не-ASCII текст, обязательно сохранять в UTF-8 с BOM (`EF BB BF`). Windows PowerShell 5.1 не распознаёт UTF-8 без BOM однозначно.
- После создания или изменения `*.ps1` проверять BOM и синтаксис парсером штатного Windows PowerShell 5.1, а не только PowerShell 7.
- Не применять к PowerShell-скриптам форматтеры или механические перезаписи, которые удаляют BOM.
- Файлы `*.cmd` по возможности оставлять ASCII-only; не добавлять в них кириллицу без отдельной проверки в `cmd.exe` Windows 10.
